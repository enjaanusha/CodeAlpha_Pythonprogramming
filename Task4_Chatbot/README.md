# CodeAlpha Basic Chatbot

## Project Overview

This project is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

The chatbot interacts with the user through the console and provides predefined responses based on the user's input.

## Features

- Greets the user
- Responds to "hello" and "hi"
- Responds to "how are you"
- Responds when asked its name
- Provides help information
- Handles unknown messages
- Exits when the user enters "bye"
- Uses a continuous conversation loop

## Technologies Used

- Python 3
- Functions
- If-elif statements
- While loop
- String handling
- User input and output

## Supported Commands

| User Input | Chatbot Response |
|------------|------------------|
| hello | Hi! Nice to meet you! |
| hi | Hi! Nice to meet you! |
| how are you | I'm fine, thanks! |
| what is your name | I'm a simple Python chatbot. |
| help | Displays available commands |
| bye | Goodbye and exits the program |
